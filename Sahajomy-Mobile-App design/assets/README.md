# Mobile Assets

Store only approved production assets here before Flutter implementation:

- adaptive Android launcher icon foreground/background
- monochrome notification icon
- splash mark and wordmark variants
- approved empty-state or onboarding illustrations
- store listing screenshots and feature graphic after UI approval

QR codes, barcodes, status icons, scan targets, and code placeholders must be generated at runtime or drawn with app-native components. Never check real warehouse access tokens, collection codes/PINs, customer labels, or parcel photographs into this folder.

Current HTML previews use code-based placeholders and require no raster assets.
