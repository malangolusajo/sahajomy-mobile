# Mobile copywriting rules

Use the same service vocabulary across mobile and sahajomy.co.tz: **China Address, Sea Cargo, Air Cargo, Product Sourcing/Agiza, Shipment Tracking**.

Primary customer promise: **Ship, source, and track goods from China to Africa.**

Prefer action copy that says exactly what will happen: `Continue to review`, `Confirm booking`, `Prepare address`, `Copy complete address`, `Show collection QR / PIN`. Avoid generic `Submit` when a specific verb is available.

Status labels follow backend/user-facing mappings consistently and must not be replaced with stylistic synonyms.
