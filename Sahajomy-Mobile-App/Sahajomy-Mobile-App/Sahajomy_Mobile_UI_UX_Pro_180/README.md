# Sahajomy Mobile UI/UX — Professional 150-Screen Pack

This is the **150-screen interim professional design pack (screens 000–149)** requested for review before the extended set.

## Brand rule
`assets/SahaJomy_Final_For_White_Shirt.svg` is the supplied original Sahajomy logo and is copied unchanged. The UI may only place, scale and pad the artwork. No derived S, bolt, monogram, recolor or redraw is included.

## UX direction
- Modern logistics-first mobile UI with strong hierarchy, compact operational lists, generous touch targets and clear next actions.
- Mobile design system: brand navy/coral UI, with the original logo gold used only as a restrained signature accent.
- Customer, Cargo Company, Sourcing Agent and Super Admin experiences are separated by role and task.
- Sea and Air customer booking use Choose service → Cargo details → Review, with the final mutation only on confirmation.
- Scanner and collection flows include manual/recovery patterns and explicit parcel/status information.
- Dedicated loading, empty, offline, 403, 409, 410, 422 and 429 screens are included.

## Contents
- `screens/`: 150 rendered PNG screens
- `html/`: editable HTML/CSS source for every screen
- `assets/`: original unchanged logo and shared UI CSS
- `manifest.json`: screen inventory
- `design_tokens.json`: implementation-ready visual tokens
- `contact_sheets/`: overview boards
- `docs/`: backend/UI and copywriting notes
